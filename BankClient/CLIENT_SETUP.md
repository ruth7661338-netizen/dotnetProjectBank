# הרצת הלקוח (React) מקומית

## 1. התקנת חבילות

```
npm install
```

## 2. הגדרת כתובת ה-API

```
cp .env.example .env
```

ברירת המחדל היא `http://localhost:5100` (הפורט שמוגדר ב-`launchSettings.json` של `BankProject.API`). אם השרת שלך רץ על פורט אחר, שני את `VITE_API_BASE_URL` ב-`.env` בהתאם.

## 3. הרצה

```
npm run dev
```

האתר יעלה על `http://localhost:5173`. **חשוב:** ודאי שהשרת (`BankProject.API`) כבר רץ, אחרת בקשות ה-API ייכשלו.

אם מקבלים שגיאת CORS בדפדפן, ודאי שהכתובת שממנה הלקוח רץ (`http://localhost:5173` כברירת מחדל) מופיעה תחת `ClientOrigins` ב-`BankProject.API/appsettings.json`.

## משתמשי דמו

| Role     | Email                | סיסמה     |
|----------|------------------------|-----------|
| Clerk    | clerk@bank.local       | Demo1234! |
| Customer | customer@bank.local    | Demo1234! |

## מבנה המסכים

- **התחברות / הרשמה** — שומר JWT ב-`localStorage` ושולח אותו כ-`Authorization: Bearer` בכל קריאה.
- **רשימה** — פקידה (Clerk) רואה את כל החשבונות עם pagination אמיתי מול השרת (עמוד קודם/הבא). לקוחה (Customer) רואה רק את עצמה ואת החשבונות שלה.
- **פרטי חשבון** — יתרה, תגיות, היסטוריית תנועות.
- **פעולה** (`/accounts/:id/action`) — הפקדה/משיכה/העברה, עם **טיפול מפורש בתשובת 409** (הפעולה שמתחרים עליה): מוצגת הודעה ברורה ("הפעולה נכשלה (409 - התנגשות)") עם כפתור "נסי שוב", נפרד מהצגת שגיאות ולידציה רגילות.
