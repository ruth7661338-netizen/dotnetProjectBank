# מערכת ניהול בנק — לקוח (React)

לקוח React מינימלי שמדגים את ה-Web API של מערכת הבנק (`BankProject`) עובד קצה-לקצה. **הלקוח הזה לא נבדק על עיצוב או מבנה קוד** — רק על כך שהוא מראה שהשרת עובד: התחברות/הרשמה, רשימה עם pagination אמיתי, פעולה על המשאב המוגבל, וטיפול ברור בתשובת 409.

## מסכיםnpm run

- **התחברות / הרשמה** — שומר JWT ושולח אותו כ-`Authorization: Bearer` בכל קריאה.
- **רשימה** — פקידה (Clerk) רואה את כל החשבונות עם pagination אמיתי מול השרת; לקוחה (Customer) רואה רק את החשבונות שלה.
- **פרטי חשבון** — יתרה, תגיות, היסטוריית תנועות.
- **פעולה** (הפקדה/משיכה/העברה) — עם טיפול מפורש בתשובת 409 (התנגשות concurrency), נפרד משגיאות ולידציה רגילות.

## הרצה מקומית

הוראות מלאות (כולל משתני סביבה ומשתמשי דמו) ב-**[CLIENT_SETUP.md](./CLIENT_SETUP.md)**. בקצרה:

```
npm install
cp .env.example .env
npm run dev
```

**דורש שהשרת (`BankProject.API`) כבר רץ** בכתובת שמוגדרת ב-`.env` (ברירת מחדל: `http://localhost:5100`).
